# Support

SurroundCore is community software and the complete project is free to use.

- Bugs and feature requests: GitHub Issues
- Development/design discussion: GitHub Issues or Discussions when enabled
- Contributions: pull requests are welcome
- Donations: entirely optional; no feature or support level is tied to payment

When reporting playback problems, include the source format, endpoint model/firmware, selected transport, render plan and relevant logs. Please remove credentials and private URLs first.
