# SurroundCore Support

SurroundCore is currently a **developer preview**. Support is best-effort while the Core, endpoint agents, storage layer and streaming-provider integrations are still under active development.

## Bug reports and technical support

Please use [GitHub Issues](https://github.com/lurcheous73/SurroundCore/issues) for reproducible bugs, installation problems and feature requests.

When reporting a problem, please include:

- SurroundCore version or commit SHA
- Debian version and deployment type (Proxmox LXC, VM, bare metal/NAS or endpoint)
- Relevant endpoint/output type (ALSA, HDMI, Sonos, AirPlay, Chromecast, etc.)
- What you expected to happen
- What actually happened
- The smallest useful section of logs or error output
- Steps that reproduce the problem

Please **remove passwords, API keys, OAuth tokens, bearer tokens, cookies, private URLs and other credentials** before posting logs publicly.

## Email support

A dedicated SurroundCore support mailbox will be published here once assigned.

Until then, use GitHub Issues so support requests, fixes and workarounds remain searchable for other users.

## Security or credential exposure

Do not post exposed credentials or sensitive security information in a public issue. Revoke or rotate any exposed credential first. A private email route will be added here with the dedicated support mailbox.

## Scope

At this stage, support covers SurroundCore itself, its documented Debian 13 deployment, endpoint agents and integrations implemented by this repository. Problems inside third-party streaming services, proprietary clients, network hardware or unsupported operating systems may need to be reproduced independently before they can be diagnosed as a SurroundCore fault.
